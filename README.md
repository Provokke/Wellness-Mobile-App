# 🌿 Wellness App

A modern, intuitive web-based wellness app built with React and deployed on Vercel. This project showcases a clean UI and responsive design focused on user wellbeing, routines, and habit tracking.

👉 Live Demo: https://wellness-app-mauve.vercel.app/  
📂 Codebase: https://github.com/Provokke

---

## 🚀 Features

- Responsive UI (desktop & mobile)
- Wellness dashboard
- Habit, routine & goal tracking
- Clean, minimalist design
- Fast performance

---

## 🛠 Tech Stack

- React  
- Next.js  
- TailwindCSS  
- Framer Motion  
- Vercel  
- GitHub  

---

## 📁 Project Structure

/src

├── components/ # Reusable UI components

├── pages/ # App pages and routing

├── styles/ # Styling

├── utils/ # Helper functions

├── assets/ # Images & icons



---

## 🔧 Installation

Clone the repo:

git clone https://github.com/Provokke/wellness-app
cd wellness-app


Install dependencies:

npm install


Run the dev server:

npm run dev


Open in browser:

http://localhost:3000


---

## 📈 Deployment

Optimized for Vercel.

1. Push to GitHub  
2. Import repo into Vercel  
3. Automatic builds & deploys  

Live Site:
https://wellness-app-mauve.vercel.app/
