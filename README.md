# 🌿 Wellness App

A modern, intuitive web-based wellness app built with React and deployed on Vercel. This project showcases a clean UI and responsive design focused on user wellbeing, routines, and habit tracking.

👉 Live Demo: https://wellness-app-mauve.vercel.app/  
📂 Codebase: https://github.com/Provokke

---

## 🚀 Features

- Responsive UI (desktop & mobile)
- Wellness dashboard
- Habit, routine & goal tracking
- Clean, minimalist design
- Fast performance

---

## 🛠 Tech Stack

- React  
- Next.js  
- TailwindCSS  
- Framer Motion  
- Vercel  
- GitHub  

---

Live Site:
